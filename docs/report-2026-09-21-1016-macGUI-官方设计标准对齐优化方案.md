## 4. P0 窗口 · 导航层

改动集中在 `AVDCApp.swift`、`RootView.swift`，新增 `Commands.swift`。

### 4.1 场景与菜单

```swift
// Sources/AVDCApp/AVDCApp.swift
Window("AVDC", id: "main") { RootView() }     // 单窗口
    .defaultSize(width: 1080, height: 720)
    .windowResizability(.contentMinSize)
    .windowToolbarStyle(.unifiedCompact)
    .commands { AVDCCommands() }
Settings { SettingsScene() }                   // ⌘,（系统偏好窗口）
```

- 菜单顺序按 HIG：App → 文件 → 编辑 → 显示 → 处理 → 窗口 → 帮助
- App 菜单：About 项经 `CommandGroup(replacing: .appInfo)`；
  删 New（`replacing: .newItem`）；设置走系统 `Settings`
- 处理：开始 ⌘R / 停止 ⌘.；文件：选择目录 ⌘O、导出日志 ⌘E；
  显示：⌘1–⌘3 切页；不可用项置灰不隐藏

### 4.2 工具栏（逐页 items；工具页暂无主操作，随实现补）

| 页面 | 尾部 primaryAction | 其余 |
|------|------------------|------|
| 主页 | 开始处理/停止（prominent） | 浏览目录、模式 Picker、`navigationSubtitle` 显示 `current/total` |
| 日志 | 导出 ⌘E | 级别 Picker、清空（确认）、`searchable`、`ToolbarSpacer(.fixed)` |
| 设置窗口 | 保存配置 ⌘S | 恢复默认（destructive + 确认）、`searchable` 过滤 35 字段 |

### 4.3 侧边栏（3 项）

- 同步改 `Page` 枚举（`AVDCAppCore/AppModel.swift`）：删
  `settings`、`about` 两 case，⌘数字快捷键随之调整
- 宽度 `.navigationSplitViewColumnWidth(min: 180, ideal: 220, max: 280)`
- 行高取 HIG 中档 28pt / 20px / 13pt；不足两组，不硬造 `Section`
- 彩色图标：`.listItemTint(.multicolor)` 或
  `symbolRenderingMode(.multicolor)`（macOS 27 彩色图标回归，改后目检）
- Golden Gate 贴边由系统渲染，**不叠任何背景**

## 5. P1 内容层视觉令牌

新增 `Sources/AVDCApp/DesignTokens.swift`，全项目引用：

1. **语义色**：`Color(nsColor: .labelColor / .secondaryLabelColor /
   .separatorColor / .windowBackgroundColor)`；状态色用
   `systemGreen / systemRed / systemOrange`，禁用 `.green/.red`
   字面量（不响应提高对比度）
2. **字体**：全部改系统文本样式（`.largeTitle` / `.headline` /
   `.body` / `.caption`），清掉 34 / 18pt 硬编码
3. **间距令牌**：`enum Metric`，档位限 4 / 6 / 8 / 16 / 20；
   圆角取 Golden Gate 收敛值（卡片 8、大容器 10）
4. **去自绘卡片背景**：`ToolCardView` 改 `GroupBox`，或
   `.background(.background.secondary, in: .rect(cornerRadius: 8))`
   + `.strokeBorder(.separator)`
5. **设置页**改 `Form { … }.formStyle(.grouped)`，保存与恢复默认移入工具栏
6. **日志页**改 `List`（虚拟化）替代 `ScrollView + LazyVStack`，
   删自绘 filterBar

## 6. P2 交互与状态

- **快捷键**：工具栏按钮与菜单同一套（⌘R / ⌘. / ⌘S / ⌘O /
  ⌘E / ⌘1–⌘3），不做「有按钮无菜单」
- **破坏性确认与空状态**：清空日志、恢复默认 →
  `.confirmationDialog` + `role: .destructive`；未选目录/无结果/
  无日志 → `ContentUnavailableView`（标题 + 一句话 + 主操作）
- **焦点与提交**：`@FocusState` 聚焦输入目录，`.onSubmit` 触发开始
- **可访问性合并**：结果行、日志行用
  `accessibilityElement(children: .combine)`；装饰图标
  `.accessibilityHidden(true)`
- **进度**：`ProgressView(value:)` 加 `.accessibilityLabel`；
  运行中 `navigationSubtitle` 显示 `current/total`
- **提示与命中区**：图标按钮 `.help()`，命中区 ≥ 44pt
- **列表稳定性**：`results.reversed()` 改倒序存储

## 7. P3 玻璃使用规范

只有一处候选：主页运行中的进度 HUD（浮在结果列表上方）。

```swift
GlassEffectContainer(spacing: 12) {          // 单容器分组
    HStack { ProgressView(value: p); Text("\(c)/\(t)") }
        .padding(.horizontal, 16).padding(.vertical, 10)
        .glassEffect(.regular.tint(.accentColor), in: .capsule)
}
```

约束（写入令牌文件注释 + 评审清单）：

- 只用 `.regular`；`clear` 需「媒体背景 + 可加暗层 + 明亮前景」
  三条件，本应用不满足 → 禁用
- 屏幕玻璃层 ≤ 12；就近玻璃必须同容器（实测 8 层 2.8ms → 0.6ms）
- 不叠玻璃于玻璃，改用填充/虚化表达层次
- 禁止内容卡片加玻璃；禁止在 split view / 侧边栏 / 工具栏叠
  自定义背景（违「玻璃属导航层」且遮挡滚动边缘效果）
- 滚动边缘效果：内容 List 直接贴工具栏下方，必要时
  `.scrollEdgeEffectStyle(.soft, for: .top)`
- 验证：Instruments → Metal System Trace → Glass Layer 过滤器

## 8. P4 无障碍与降级

系统组件自动适配；自绘 HUD 与卡片需显式读三个环境值：
`accessibilityReduceTransparency` / `ReduceMotion` /
`colorSchemeContrast`：

- 减透明度 → HUD 由玻璃降级为 `.regularMaterial` 或实底
- 提高对比度 → 卡片描边改用 `labelColor`
- 减弱动效 → HUD 出现/消失直接跳变，不做形变
- VoiceOver：逐元素核对（状态点、卡片图标、结果行、日志行、
  进度条）；文字只用语义色层级，禁小字号 tertiary 压玻璃
- 测试矩阵：浅/深色 × 减透明度 × 减弱动效 × 提高对比度

## 9. P5 无 bundle 落地（决策 4）

- **About 面板**：`NSApplication.shared
  .orderFrontStandardAboutPanel(options: [.applicationName: "AVDC",
  .applicationVersion: …, .credits: …])`；内容取自新增
  `AppInfo.swift`（版本唯一来源，与 CLI `--version` 对齐）
- **菜单栏 App 名**：无 bundle 时取进程名，故把 SPM product 改
  为 `AVDC`（`.executable(name: "AVDC", targets: ["AVDCApp"])`），
  App 菜单才显示「AVDC」；同步更新 AGENTS.md/README 启动路径
  （`.build/debug/AVDC`）
- **最低系统**：由链接期 `minos = 26.0` 承担，旧系统直接拒绝启动
- ⚠️ 仍依赖 cwd：`Bridge.findProjectRoot()`（`Bridge.swift:89-100`）
  从 cwd 向上找 `cli/cli.py`，**必须从项目根启动**（双击启动
  需再讨论 bundle）
