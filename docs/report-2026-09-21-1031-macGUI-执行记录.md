## 2. 与方案的偏差（3 处，均为「更少入口」方向）

| 偏差 | 原因 |
|------|------|
| 主页工具栏不放「浏览目录」 | 输入行已有「浏览…」按钮，再加一处即双入口；⌘O 全局可用 |
| 工具栏按钮不注册 `.keyboardShortcut`（仅 `.help` 标注） | 菜单已注册同键，重复注册会造成 AppKit 键等同冲突 |
| 工具页暂不设工具栏项 | 8 个工具均「待实现」，先留空，随实现补 |
